# 分支记忆与恢复

用 `tavern_memory` 按需搜索和读取当前分支的场景、人物所知、关系、物品与未完成线索。原作者的狐忆注入槽不是通用设定，也不是自动导入成功的证明。

写作前核对当前变量与相关正式历史；记忆和压缩摘要有冲突时回到原始记录确认。原生压缩清理对话表面后，通过读取材料恢复，不重新生成已提交正文或重算变量。

正式正文提交后，已有后台协调器维护变量和持久记忆。前台草稿及假设方向不写入权威事实；分叉、回退和恢复沿用 Timeline 与记忆版本校验。

原玄狐的数据库、平行世界控制器、狐刻与手机界面是否接入，以设置页能力清单为准。未接入的模块不声称运行成功，不用原脚本缓存或默认示例替代真实资料。
