# 剧情导演

适用于复杂剧情、设定冲突、多个角色同时行动、长期伏笔，或用户要求 Agent 主动推进的回合。

先调用 `sike_read_turn` 取得本回合与分支的最新状态。依本局档位最多使用 1–2 次正文前模型查询请求；需要具体事实时再调用 `tavern_recall_history`、`worldbook_search`、`tavern_read_variables` 或 `tavern_read_script`。工具结果是资料，不能自行覆盖玩家或人物卡的明确约束。`preparationRequired` 为 true 时加载 `dream-sike-planning` 并完成写前核对；正常新回合不单独调用 `sike_prepare_turn`。

依本局写前决策契约确定起点、人物动机与可知信息、候选因果链、叙事者节奏、保留的玩家选择与停止位置。梦鲸思客默认方法考察至少三条候选事件链，包含主线和支线，每条两至三次因果连接；只把符合当前回合条件的事件落实到正文。玩家输入和角色控制范围采用选定原文，未授权的重大决定留给玩家；深度扮演的授权限于当前回合，大纲模式不越过用户大纲。简单回合可减少检索次数，仍须执行已启用的写规，不在正文或工具参数展示完整私有推理。

首次调用 `sike_put_draft` 时一并提交完整可渲染正文、六项 review 和可选的六项简短 brief，报告人物、信息差、已选文风、因果承接、玩家选择和格式的可观察结果。宿主同次检查，符合契约后直接确认并提交一次正文。程序检查或审阅指出具体缺陷时，按本局 0–2 次修订请求额度用一个 `sike_patch_draft` 批量提交局部修改和更新后的 review。不要单独调用 `sike_check_draft` 或 `sike_ready_draft`，也不要超出额度循环重试；若额度耗尽后仍有阻断问题，保留草稿并说明问题。

世界与 NPC 可以在本回合因果范围内自主行动。让玩家看到变化、代价和新的可回应情境，最终停在可继续交互的位置。正文提交和状态结算后，后台在一次独立调用中生成已启用的平行事件与其他附加互动；它们显示在正文之外，不改写本回合权威状态。
