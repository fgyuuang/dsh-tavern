# 剧情导演

适用于复杂剧情、设定冲突、多个角色同时行动、长期伏笔，或用户要求 Agent 主动推进的回合。

本次请求已装配的作者原文和场景事实可直接使用；缺少具体材料时才用 `sike_read_turn`、`tavern_recall_history`、`worldbook_search`、`tavern_read_variables` 或 `tavern_read_script`。档位约束可选查询投入，正文生成与最终提交始终优先。`preparationRequired` 描述作者内部核对方法，不强制额外 Skill、read 或 prepare 请求。

依本局写前决策契约确定起点、人物动机与可知信息、候选因果链、叙事者节奏、保留的玩家选择与停止位置。梦鲸思客默认方法考察至少三条候选事件链，包含主线和支线，每条两至三次因果连接；只把符合当前回合条件的事件落实到正文。玩家输入和角色控制范围采用选定原文，未授权的重大决定留给玩家；深度扮演的授权限于当前回合，大纲模式不越过用户大纲。简单回合可减少检索次数，仍须执行已启用的写规，不在正文或工具参数展示完整私有推理。

用一次 `sike_put_draft({text,review?,brief?})` 保存完整可渲染正文，宿主检查后直接提交。也可直接输出完整正文。review 和 brief 可省略，不为结构回执增加模型调用。只有已经发现具体改进且希望继续优化时传 `finalize:false`，再以批量 `sike_patch_draft` 在本局可选预算内局部优化；预算结束即提交可用正文。确定性格式和协议缺陷按当前版本修复，不占可选文风修订预算。

世界与 NPC 可以在本回合因果范围内自主行动。让玩家看到变化、代价和新的可回应情境，最终停在可继续交互的位置。正文提交和状态结算后，后台在一次独立调用中生成已启用的平行事件与其他附加互动；它们显示在正文之外，不改写本回合权威状态。
