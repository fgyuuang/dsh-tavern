# 平行事件

仅当人物卡、剧本或当前情节确有并行线索时启用。先判断事件是否属于本回合的时间范围、谁会感知、何时对玩家产生后果。不要为了展示世界活跃度而凭空开出过多支线。

可以让 NPC 在玩家视线外行动；其行动应符合动机、能力、位置与已知信息。正文只呈现当前叙事视角可以接触的部分，必要的幕后结果交由现有后台记录和状态工具维护。

并行线索与正文应互相呼应，不挤占玩家行动空间，也不把下一回合的玩家选择预先写死。对高影响事件，先查世界书或历史，避免与已有状态冲突。
