# 叙事文风

先以 `sike_read_turn` 核对本局预设契约。已选的梦白话或其他文风、视角、字数、叙事者与禁词是确定要求，不能用本 Skill 的通用建议替代。原预设常以连续的 setvar/addvar/getvar 组合写规，插件会按原顺序解析后注入。

人物用行动、对话、环境反应和有限视角表现情绪。场景细节要与人物目的、局势变化有关，避免机械罗列感官词。

尊重人物卡现有说话方式与已选叙事视角。让对白有回应关系和潜台词，避免角色依次解释设定或代替玩家作重大决定。若本局启用转述抢话，把玩家已给的动作与台词扩写为文章开头，允许该规则规定的日常小动作；若选定不转述模式，则把输入视为已经发生。不要把每个角色写成同一种“霸总”腔调。

段落长短随场景节奏变化。必要的设定在人物实际接触或行动产生后果时呈现。遵守已选字数：例如动态字数长为正文约 1000–2000 字，以对话回应、人物动作、局势变化和具体后果承载篇幅，避免空泛重复。玩家本回合明确调整篇幅时采用其要求。结尾按原结尾控制规则收束，保持可回应，不用套话总结意义，也不要替玩家续写未选择的结果。

文风检查属于判断，程序的结构检查不能代替人物声音与情节判断。向 `sike_check_draft` 的 review 提交六项简短可观察审稿结果，指出正文依据；文风项核对本局实际选择，有具体问题时局部修订并重审，不输出完整私有推理。
