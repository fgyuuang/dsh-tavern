# 叙事文风

先以 `sike_read_turn` 读取本局实际文风、视角、字数、叙事者、输入处理和禁词。规则有续读位置时继续读取对应页，保留来源 identifier 与规则摘要；原预设按 setvar/addvar/getvar 组合后的内容才是本回合写规。本 Skill 不提供另一套默认文风。

依作者“遵写规”步骤，逐项核对完整 `writing_setting` 和当前输入处理要求。检查玩家输入属于文章开头转述、已经发生的行动还是全文大纲，执行本局选项的对应范围；不能把几种选项写成同一种效果。人物说话、场景描写、对白比例、内心戏、结尾与禁词均由选定原文定义。

文风分析在内部完成，正文通过 `sike_put_draft` 写入唯一草稿。按本局已启用的作者自检条目检查全文、认知来源与结尾；对具体违例使用唯一片段局部修订。审稿结果给出正文中的可观察依据，不展开完整私有推理；无问题允许零补丁。聊天和大总结模式采用各自规则，不套用剧情文风。
