# 角色认知边界

遇到秘密、误会、侦查、角色分头行动或幕后事件时使用。区分三层：已提交剧情中的事实、读者可以看到的线索、当前角色实际可知的内容。

必要时用 `tavern_recall_history`、`worldbook_search` 和 `tavern_read_variables` 核对事实与时间顺序。变量值与后台记录可以指导 Agent 安排事件，但不得自动写成所有角色已知的信息。

人物可以形成错误判断、隐瞒事实或主动采取合理行动；保持其性格与处境，不用全知旁白纠正每次误会。用户未给出的玩家意图、台词和心理保持开放。对有争议的事实，把不确定性留在叙事中，避免无依据定论。
