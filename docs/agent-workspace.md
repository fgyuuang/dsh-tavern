# 角色卡项目与剧情记忆

同一张人物卡对应一个本地项目。项目下可以重新开局，也可以从已结算回合分叉；侧栏按照来源关系显示分支。项目身份独立于卡片路径，改名保留身份，删除卡片后保留已有项目与存档，重新导入同名卡片建立新的项目。

“梦境思客DSH”开启本局持久记忆。前台通过 `tavern_memory` 列目录、读取文档和搜索中文关键词；后台复用本局已有的常驻 Agent，在本轮正文提交后整理场景、人物所知、关系、线索与辅助表格。可维护 `memory/`、`characters/`、`tables/` 下的 Markdown、JSON、CSV、TXT。核心人物设定和世界规则的变更需要玩家明确要求，MVU 数值以变量工具为准。

后台使用 `tavern_memory_submit` 提交完整的新文档或删除路径。文档先写入不可变存储，提交回执保存到本轮任务；只有后台结算的同一次 Chat 事务成功，当前记忆指针才更新。变量失败、取消、过期分支回调均不能提前推广暂存记忆。允许空更新，相同内容沿用原版本。

回退恢复历史记忆指针；分叉复制选定回合的记忆到新局自己的存储根。存档格式第 2 版包含当前与回退历史依赖的文档，仍支持读取第 1 版存档。删除游戏时记忆进入原有单局数据清单。

压缩只改变 Agent 的工作上下文。每轮提供小型文档目录，旧目录随回合指引一起退出请求视图，持久文档可重新读取。原生模式的历史原文召回不受传统十轮冷却限制；同一次生成仍有六次召回预算，重复读取只在当前上下文中去重。

聊天顶部和右侧增加“本局记忆”，支持分页、搜索、读取和刷新。切换会话或分支后，迟到响应不会覆盖当前文档。此版本提供只读浏览，文档由后台 Agent 维护。

持久数据位于 profile 数据目录的 `card-projects.json` 和 `game-memory/<chat-id-sha256>/`。物理对象按内容哈希保存，逻辑文档路径存入快照；Agent 不能用路径参数访问其他局或宿主文件。单个文档最多 256KiB，本局当前文档合计 4MiB、最多 128 份；归档最多 400 个快照、64MiB，超限明确报错。

接口：`listCardProjects` 返回项目与对话归属；`getGameMemory` 返回当前分支的目录、文本页或搜索命中。正文和状态仍由 Story Timeline 提交，记忆没有独立的剧情提交入口。原预设可以切回，新游戏默认值沿用现有设置。

此版本建立 Agent 记忆维护与分支管理基础。旧 ACU 数据库专用快照导入、通用文件编辑工具、跨 Session 章节接续，以及原生状态引擎替换 MVU，继续按独立功能阶段维护。
