# 本局世界书管理

“游戏准备”增加本局世界书折叠区，收起时显示名称与启用数量。展开后按标题或编号查找并切换条目，分别统计常驻剧情、动态触发和后台变量规则。条目开关写入现有开局草稿，开始新游戏时沿用同一份世界书快照；不写入资源库原件。

准备页每四秒读取不含正文的紧凑摘要，从同一草稿显示角色卡脚本的最新选择。隐藏准备页停止刷新。保存采用世界书内容版本校验；脚本或其他操作已经修改草稿时拒绝旧设置，重新读取。读取或保存尚未完成时禁止开始游戏。

Agent 工作台的“世界书”模块及人物状态面板的“本局世界书”入口展示本局实际资料，包括禁用条目、正文搜索、启用筛选和 MVU 规则。本局快照与资源库摘要分开显示。多本绑定提供各资源库来源入口；旧存档尚无快照时明确显示资源库模式。

“同步人物卡和世界书”复用原有 applyUpdatedCard，要求前后台空闲、确认版本摘要。同步会替换本局人物卡、世界书启用状态、条目正文和脚本修改，保留聊天与游戏变量；界面明确说明范围，不在打开面板时自动同步。

回合接入记录使用现有 getWorldBookRecallLog：分支与回合筛选、召回/排除原因、模板正文以及请求匹配结果。没有历史记录时保持空状态。prepared 只表示准备，不表示实际发送；requested 只说明已关联请求，不证明模型遵循或生成成功。

修复请求循环重置前台 Frame 元数据导致日志无法关联的问题：显式记录的新 Frame 收据进入请求坐标，在同一模型回合的后续步骤保留，新回合清除。原生模板重写消息来源后仍按明确 Frame ID 定位日志；不根据最近回合猜测。常驻前缀的正文也参与实际请求文本匹配。旧日志不回填伪造发送状态。

新增接口：getOpeningWorldBook、setOpeningWorldBookEntryEnabled、getGameWorldBook。准备页开关要求 ref、boolean enabled 和 revision；旧版本被拒绝。界面通过 tavern/worldbook 注册为原生工作台插件，独立侧栏入口供原版模式使用。
