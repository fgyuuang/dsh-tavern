# 梦鲸思客统一设置页

入口：打开游玩会话，点击顶部“本局设置”，进入“预设功能设置”。本局引用梦鲸思客V4-0915时，页面直接使用原预设助手 `data.groups` 定义，不重新编写选项提示词。

## 可选内容

13 组包括模型适配、思考强度、MVU适配、文风设置、次要文风、角色设定、人称设定、抢话设定、叙事者、字数要求、角色分析、其他选开设置、输出模式。实际源文件展开为72个选项，其中71个提示词选项可以选择；原宿主“模型思考格式化”标为不可用。

两个输入项为自定义扮演角色名、自定义字数。角色名使用原局部变量名，字数使用原全局变量名；在 DSH 中两者均作为本局宏覆盖持久化，避免修改其他游戏或新游戏默认值。

选项使用原助手的名称、区间匹配、单选/多选、enable/disable及分组重置逻辑。单选的分组重置与关闭同组其他选项是原脚本中的两个不同分支，保持原实现。每次选择原子保存，从下一回合生效。来源提示词可展开逐字查看。正则、脚本状态及原有手工编辑放在高级区；有未保存高级编辑时不能操作即时保存的源选项。

## 执行与兼容

- 保存只写当前局的预设快照，保留历史、角色卡、世界书和剧情变量。原预设资源文件不变。
- 保存检查前后台、脚本和结算空闲，以及会话存储版本和预设摘要。成功后增加脚本生命周期版本并清理旧实例。
- 聊天、大总结遵守作者模式的剧情协议豁免，不强制场景、平行事件、剧情字数或写前剧情简报。
- 默认四章写前流程、文风分析重点、平行事件五项检查、自检扫描和唯一片段定位沿用作者原句；旧思考文本包装和补丁提交方式适配为原生工具。原文及哈希仍可核对。
- 原模型宿主设置、Kimi Partial效果、第三方数据库宏材料以及旧脚本流程具有明确的兼容说明。能启用对应提示词不代表这些依赖已运行；本次不宣称所有原扩展体验已完成端到端复刻。
