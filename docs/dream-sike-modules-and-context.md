# 作者模块分阶段与上下文优化

本次维护基线 `487b4f6e`，分支 `codex/dream-sike-dsh-agent`。在既有 Agent 草稿、时间线与后台任务边界内分阶段接入，不重写角色卡或原预设。

## 执行阶段

| 阶段 | 作者模块 | 原生执行 |
| --- | --- | --- |
| 写前 | 默认/V4Pro/自定义决策流程、角色分析、信息差、叙事者 | 按原文读取、核对，保存六项简短准备；不输出完整私有推理 |
| 主线草稿 | 已选文风、视角、输入处理、字数、场景 | 前台维护唯一草稿 |
| 独立剧情模块 | 梦境平行事件 `807eefad-93ca-490c-a629-1d51038e3626` | `sike_run_module(kind="parallel")` 调用同一持久后台，生成后按版本合入草稿 |
| 独立审稿 | 八股超杀 `7cfbff76-346a-400f-b47d-46e55f5fe0fa`、自检修复 `4e26a3ac-4d46-45ed-85bf-0110fbe06cd2` | `sike_run_module(kind="review")` 自动更新过期平行事件，再读取完整作者规则及当前写法，提交六维具体依据；前台可一次批量唯一定位修订 |
| 正式提交 | 主线与平行事件 | 整体检查、确认，只提交一次正文，再统一结算变量、状态与记忆 |
| 后续互动 | 旧说书 `f9b03e19-fd96-4782-8867-73ad2cbabfb9`、大调查、行动选项、小摘要 `6a8e799c-9445-44f2-a853-c6c71b92b855` | 结算后独立调用，按说书→调查→选项→摘要显示，原开关和完整原文保留 |

只有启用的作者模块才执行。旧说书和小摘要原默认禁用，更新不会自动开启。大总结和聊天模式仍是独立回复模式，第三方数据库材料仍标明接入限制。已确认的历史正文不改写，新回合采用新流程。

“平行事件”是同一世界的场外同时事件，改变正式世界事实。先合入草稿再整体提交，才能保证变量、记忆与主线一致。共创建议不代表已经发生，小摘要只记录本轮既成事实；它们没有独立剧情提交权限。

模块结果绑定正文任务、分支、草稿版本、内容、变量事实、本局世界书及作者规则摘要。有效结果重复调用直接复用；主线修改后相关结果失效，review 会自动先更新平行事件。模块失败、取消或过期保留现有草稿。修订次数不设上限，次数只作记录；`sike_patch_draft` 支持 patches 数组，按顺序一次原子应用 1–8 个局部片段，全部唯一定位成功才保存新版本。模块必须完成后才能确认正文。角色卡脚本内的协议示例和 `$&` 等字面字符不作为替换指令。后台仍每局一个持久 Agent，模块提交工具按当前任务授权，不能调用变量写入冒充审稿。

玩家直接继续下一回合时，可选后续互动生成让出后台，不拖延新的独立草稿模块；已提交正文与变量不受影响。生成未完成会标记停止，不在重启后偷偷重发。

## 上下文管理与本轮改动

稳定前缀保存人物卡、常驻世界书和长期偏好；选定前置作者规则通过原生 system 装配。每轮追加行动、动态世界书、变量反馈及记忆目录，按需检索原历史和文档。当前工具循环保持调用/结果配对，正式剧情由独立时间线保存。原生压缩保留近期原文及摘要，工作目录可在压缩后重读。

`sike_read_turn` 增加分项读取：首次仍返回完整当前材料；连续规则续页可设置 `includeMaterials=false`、`includeDraft=false`，仅请求草稿时可 `includeRules=false`。显式完整补读随时可用，压缩或重启后须重新核对原文。选择省略只改变本次工具返回，不删除作者规则、材料或历史，不伪称这些引用已经被模型重新读取。

对同一真实存档的内存副本做只读规则分页回放：两次续页完整返回共 53,497 字符，分项返回共 22,581 字符，减少 57.8%。规则正文一致、用户存档写入为零。此结果度量工具载荷字符，不能换算为实际 token、账单或缓存命中率改善。

后台独立模块只接收当前职责的作者规则；未启用模块不装配到前台。原作者的长检查协议从正文请求移到相应任务，避免每次正文采样都承担全部输出职责。拆分可能增加模型调用；版本复用及分项读取旨在减少重复输入，不能保证费用一定下降。

工作台新增“上下文缓存”：读取标准化真实 usage、按任务及模型分组；显式前缀检查只返回哈希与字符证据。旧记录缺少 usage 显示未知，不以字符数推算实际命中率。窗口占用、输入处理量与提供方缓存命中是三个不同指标。

真实旧会话样本中，前台 39 次有效用量合计缓存读取率 81.38%，后台 13 次为 87.98%；最新前台 6 次调用仍累计 949,679 输入 token。3 次规则续页重复携带 33,031 字符非规则内容。详细口径、模型切换影响与限制见 [缓存审计](context-cache-audit-20261011.md)。这些是改造前样本，不是本次上线后的节省结果。
