## Tavern 更新重点

- 存档格式 2、块包、空闲整理；回退和分叉保留最近 50 轮；历史正文保留。模型请求原文保留最近 3 轮、每局 8 MB；召回明细最近 10 轮。
- 存档与原生上下文对账，修复漏记正文、失败输入残留、回退和重新生成归属；压缩检查点保持摘要，修复 #202。
- 页面与服务端协作执行 MVU 卡脚本，服务端失败时有回退；新增 MVU 概览、装配工具，减少改卡步骤。
- 插件 API 2：按局数据、变量、世界书来源、后台任务、结算/候选/压缩扩展、独立面板、全屏界面、输入操作、静态资源。后台模型接口传递推理强度，修复 #203。
- 同轮多图、画廊、自写提示词、默认关闭的每轮自动生图；新增生图 Agent 模型并接入现有集中模型页。

格式升级会改变可回退版本范围。部署必须在停止安装后，备份完整 Tavern 数据与配置；回滚程序与升级前数据应配套使用。

## DSH 更新的接入边界

0.2 系列增加实验性的插件会话状态记录、会话恢复、动态工具/系统提示适配；修复流空闲且传输不响应取消时一直挂起的问题，改善插件更新和热重载、任务中断显示。较新桌面还有下载、附件、预设加载、诊断与退出修复。

当前 Tavern 使用经过版本校验的原生 Session 适配。直接更换内核会越过它的兼容范围；本次保持该契约，并通过已实现的等待时限、中断持久化与续写解决当前故障。迁移到 0.2 的下一步是在独立 DSH_HOME 中验证 Session/工具协议、压缩、分叉、插件加载、凭据解析与恢复，再更新兼容声明和主安装。

## 插件迁移边界

| 能力 | 当前归属 | 后续边界 |
| --- | --- | --- |
| 预设选择、作者来源、直接回复开关 | 独立 `dsh-tavern-writing-presets` 用户插件 | 插件自带宿主入口、界面和资源 |
| 全局默认与作者选项页面 | 现有宿主 UI，插件通过公开入口打开 | 按完整设置契约继续迁移，保留全部选项与原文 |
| 预设原始提示词和 Skills | 持久数据/预设目录 | 作为插件的声明资源，不复制重写作者内容 |
| 草稿工具、阶段执行、正式提交 | 宿主共享写作引擎 | 预设能力按注册表提供；提交与分支校验仍由宿主统一执行 |
| 平行事件、见解、记忆 | 现有独立模块与持久记忆 | 使用 API 2 的后台任务、按局数据、世界书来源和压缩扩展逐项迁移 |
| 角色卡/正则/助手脚本/MVU | Tavern 兼容运行时 | 使用统一生命周期与前后台执行所有权，避免多个插件重复启动 |

第一步已落地独立菜单插件，使用公共服务和 DSH 插槽；停用后原有菜单恢复。宿主增加版本为 1 的 `writingPresets` 扩展；请求只开放预设、执行策略和恢复操作，读取会话只返回菜单需要的字段。插件不读取数据文件、导入内部模块或替换 DOM。

## 验收

执行相关核心、插件、存档、模型设置检查和浏览器交互检查，不发起真实模型请求。模型和供应商配置保持用户原值。保留原维护工作树中的 `tests/request-frame-coordinates.test.mjs` 差异。合并、插件迁移、部署工具分别提交，便于审查和回滚。
