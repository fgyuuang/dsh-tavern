# 全局 Agent 预设默认配置

设置菜单新增独立的“Agent 预设”页。分别维护 DSH 原版、梦境思客DSH和狐神抚DSH的默认回复方式、作者选项、规则、正则及写作调用预算。选中模板后可将其设为新游戏默认预设。

## 持久化与范围

- 选择默认预设沿用 `defaultPlayPresetId`。
- 每个模板存储在持久设置文件的 `globalAgentPresets[presetId]` 中，包括版本号、作者规则快照、回复方式和调用预算。
- 作者选项编辑复用现有预设配置组件与原作者规则处理函数，不重写作者提示词，也不修改预设库原件。
- 新局在创建时深拷贝模板；已存在会话的重入直接恢复旧局，不重新套用默认模板。
- 按用户确认，仅供以后新建对话继承，不批量切换已有对话。
- 模型、用户称呼、后台结算等共用新局默认设置继续沿用 DSH Tavern 设置中的既有值。

## 一致性

服务端只接受选项变更，不接受客户端上传任意运行快照；作者变更校验快照摘要，持久写入额外校验模板修订号。过期页面保存失败并提示重新载入。预设之间的默认副本相互独立，不将卡片或聊天状态放入全局模板。

## 界面入口

- 设置 → Agent 预设：新局默认模板及完整作者功能设置。
- 设置 → DSH Tavern → 已有游戏预设：逐局调整已有游戏。
- 开局对话：默认选中全局 Agent 及其回复方式，仍允许本次开局覆盖。
