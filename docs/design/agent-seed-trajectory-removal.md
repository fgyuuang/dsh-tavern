# 移除写作 Agent 固定模拟对话

适用于梦境思客DSH、狐神抚DSH的 Agent 回复方式。作者预设、Agent 执行契约、人物卡开场和玩家真实消息继续保留。

- 新局初始化不再写入三条 v1 synthetic-trajectory 消息。
- 已有局不删除原生会话历史；模型请求按三个固定种子消息 ID 的格式、消息角色、来源和版本识别并过滤旧种子。
- 分支和导入会话沿用旧会话种子 ID 时，同样能够识别。只引用同样文字的真实玩家消息不会被过滤。
- 压缩前采用同样过滤，避免原始种子进入新的摘要或最近原文附录。
- 原版 DSH 预设、单次回复模式和卡片工作台仍沿用原有逻辑。
- 旧摘要已经产生的转述不做关键词删改，避免损坏剧情记忆；历史审计视图仍可显示过去实际写入的旧种子。

移除后，不再用通用模拟承诺规定所有玩家输入都要扩写、允许接管所有角色或禁止工具与附加输出。这些行为由所选作者选项和 Agent 执行契约决定。
