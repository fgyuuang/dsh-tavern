# 输入区预设与模型选择

## 交互

- 移除输入区独立的“强度”控件，使用 DSH 原生模型选择菜单自带的“推理等级”面板。可用档位来自当前供应商对应模型的元数据；未声明档位的模型使用其默认值。
- 输入区新增单个紧凑的预设入口，展开后选择本局 Agent 预设、酒馆预设来源与“酒馆直接回复”开关，也能打开作者功能选项。
- 修改调用现有本局 RPC，从下一回合生效，前后台忙碌时禁用切换。菜单不改新局全局默认。
- 弹层通过 portal 避免被输入器裁切，支持 Escape、外部点击、关闭后焦点返回和窄屏宽度限制。

## 选项消失的原因与修复

原工作台使用 isWritingAgentView 判断是否可见；该判断排除了 sillytavern-once，因此切换成酒馆单次回复后整个工作台被隐藏。服务端 selectGenerationMode 只更新执行模式及相应生命周期，仍保留 runtimePresetSnapshot，作者选项并未删除。

工作台现在允许作者 Agent 预设与酒馆单次回复访问，作者设置随 playPresetId/generationMode 更新重新读取。单次回复隐藏 Agent 草稿模块，继续提供作者功能、世界书、状态和本局配置。独立创作设置页也跟随模式刷新。

## 验证范围

隔离浏览器模拟接口检查菜单选卡、酒馆预设切换、回复模式切换、保存失败保留选择、作者设置入口、运行忙碌禁用、切换会话关闭弹层、键盘与窄屏布局。原作者选项、模式服务及模型设置使用已有相关专项检查。没有真实模型请求。
