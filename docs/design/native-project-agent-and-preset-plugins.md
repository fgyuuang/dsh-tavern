# 项目 Agent 与写作预设插件

## 行为边界

- 游玩：角色卡、世界书、作者设置与消息渲染；酒馆直出继续使用整份原预设的注入顺序。
- 卡片：现有资源编辑与卡片调试任务。
- Agent：独立插件注册的项目工作区，使用 DSH 原生标准 / PTC / 极简 / 创造四种 preset。新建前选择，开始后遵守原生锁定；不会启动剧情帧、sike 工具流程或状态结算。

`dsh-tavern-project-agent` 通过 `tavernUi.registerSidebarWorkspace` 增加第三个入口。此扩展传入 React component 与原生 Session 编号 store；卸载自动释放订阅和界面。Tavern 只为已绑定的游玩/卡片 Session 装配提示词；项目 Session 使用原生消息、过程、工具与压缩界面。

## 持久目录和上下文

默认项目目录为数据根下 `project-workspace/`；首次启动补建 PROJECT.md、AGENTS.md、memory/INDEX.md、memory/current-task.md 和两个按需 Skills。使用独占创建保护用户已有文件。目录可以在 Agent 面板改为已有项目；不向外部项目自动写入这些默认说明。

项目记忆保存事实、来源、决定、当前任务与下一步；原生压缩后根据索引恢复相关内容。角色卡/世界书/预设保留资源源文，按任务读片段，不能把整库和脚本实现作为每次请求的固定上下文。

写作 Agent 在最终模型请求完成所有模板投影后，记录其中确实出现的作者规则全文哈希。`sike_read_turn` 默认自动复用：仅当当前 turn/step 的请求包含相同全文时，返回规则索引并记录已送达范围，省去第二份工具正文及多余分页调用。显式 `includeRules: true` 强制原文；缺少证据、规则变化、原文未注入或摘要替代原文时恢复完整分页。证据只在内存中保留，不从旧回执推断模型仍有原文。

草稿读取只在 report 中返回一份分页正文；外层 draft 仅带元数据，`includeDraft: false` 不再通过另一字段重发完整草稿。这减少工具上下文，并不承诺供应商的真实缓存命中率或生成耗时；实际缓存仍由模型请求统计核对。

## 写作预设插件

`dsh-tavern-dream-sike` 与 `dsh-tavern-hushen` 分别调用 `tavern.registerWritingPreset` 注册稳定 ID、名称和来源。注册在插件生命周期结束时撤销；缺失插件不能用于新游戏或新切换，当前局的快照、作者选项和历史仍可读取。

原作者提示词仍在现有持久预设库与游戏快照中，未替换成新编写的提示词。当前 native preset、编译器、草稿/提交、分支和状态事务仍作为宿主共享引擎；两个插件是独立的预设提供者，不把宿主内部模块导入用户插件。共享引擎的后续扩展必须保持已有 ID、用户选项与存档版本兼容。

`dsh-tavern-writing-presets` 继续提供输入区菜单。菜单及全局 Agent 预设页显示提供者来源；回复方式与作者设置独立，不因启用酒馆直出而隐藏设置。

## 前端回归修复

Agent 正式正文的 Timeline-only 投影曾遗漏 `scriptLayer`，现在与原生文本承载的正式正文使用同一组选项。暂停正文按需请求当前显示正则的只读投影，在无脚本、无 Helper 桥的 iframe 中显示 HTML/CSS；变量结算只在最终提交后发生。折叠历史版本不发起预览读取。

## 验证边界

专项测试覆盖原生 Session 的预设选择顺序、无剧情发送、工作区文件不覆盖、注册持久化、native 提示词和工具保留、插件卸载、正式脚本层与暂停前端。浏览器检查使用隔离 Edge 页面，不调用模型，不改玩家当前存档。真实原生模式的模型行为仍需在专用验证会话通过 Agnes 验收。
