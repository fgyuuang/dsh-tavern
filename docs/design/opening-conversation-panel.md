# 开局作为对话

选卡库保留资源选择功能；选定人物卡后，开局准备通过 DSH 公开的 `main` keyed slot 显示在主内容区，不再显示准备弹窗。会话和原生 Agent 预设在点击“开始新游戏”时才创建，避免提前触发预设锁定。

## 界面

- 作者开场正文 → 左右切换开场 → 可编辑的首条玩家消息 → 显式开始。
- 模型、Agent 预设、单次回复模式、世界书和玩家称呼收进可展开的设置区；缺少前台模型时自动展开。
- 世界书控件始终挂载，折叠只隐藏设置，不影响读取、卡面开关和就绪检查。
- 卡面按钮只填入输入草稿，不自动触发模型。启动前继续校验世界书就绪状态。

## 卡面生命周期

准备状态仍由侧栏控制器维护。正文通过 React portal 渲染到稳定的容器，主内容 slot 只负责提供位置。正常收起、切换工作台和选择已有对话前，将容器移回隐藏停放区；支持 `Element.moveBefore` 的浏览器保留 iframe 文档、表单和脚本实例。旧浏览器回退到普通 DOM 移动，可能重新加载 iframe。实际放弃或成功开局后才销毁准备正文、释放私有准备数据。

人物卡开场的原生消息 ID 前缀为 `tavern-opening:`。显示层独立识别该前缀，不将其当作 Agent 私有草稿隐藏；正式正文仍只由回合最后一步显示，内部写作步骤保持原有规则。
