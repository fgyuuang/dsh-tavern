# Agent 工作台：前端与交互

这次改组只调整前端组件、模块入口及显示偏好。生成策略、作者提示词、草稿提交与后台结算规则由现有运行层继续负责。

## 空间分工

主区域用于正文阅读与玩家输入。输入框上方保留当前进度、工作台入口和可收起的行动工具；移动端沿用输入焦点收起工具以及短视口避让，发送按钮不被工作台覆盖。候选生成、重新生成、回退、编辑、压缩和插件动作仍走现有入口。

DSH 原生侧栏承载 Agent 工作台。一个导航对应五个内置模块：创作设置、正文与过程、分支记忆、人物与状态、本局配置。模块显示描述和当前选中状态，管理页允许按本局隐藏和恢复模块。窄屏导航改为三列紧凑布局，内容随工作台滚动。

## 插件分工

工作台宿主只负责导航、显示偏好、挂载和错误隔离；原来的设置、草稿、记忆与状态组件各自负责读写、刷新和清理。`tavernUi.registerWorkbenchPanel` 是新增浏览器版本2接口，第三方模块与内置模块走同一个注册路径。插件通过 DSH Context effect 管理撤销，侧栏通过 Better Sidebar 注册，不另建聊天或业务状态存储。

只对已访问且声明 keepAlive 的模块保留编辑状态，隐藏时传 visible=false；默认第三方模块离开即卸载。显示偏好和当前模块仅存本地、按前台游戏 ID 隔离，未知或已卸载模块不会阻断导航。隐藏界面不等于停用生成能力。
